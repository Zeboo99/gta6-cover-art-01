Solmar Cover Studio — an offline web app that turns your photos into GTA-style multi-panel poster cover art: three photo panels with crop and positioning, bold caption lettering, sunset and neon colour grades, exported as PNG in 1080×1080, 1080×1350 and 1920×1080.

## Run it

```sh
python3 -m http.server --directory app 8080
```

Then open http://localhost:8080 in desktop Chrome. To build the entry: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
